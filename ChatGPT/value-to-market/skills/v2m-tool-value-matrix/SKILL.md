# Value Matrix

A strategy tool: value does not only flow from brand to customer, it circulates through an ecosystem, brand to supplier, brand to partner, partner to customer, platform to complementor. This matrix, after **Simone Cicero's Value Matrix** (Platform Design Toolkit), reads the whole board of value exchange so the strategy accounts for every relationship the business creates value for or with, not only the buyer. It sits in the Strategy phase because deciding how value moves across and inside the ecosystem is a company-level choice; it then tells the later customer canvas which single intersection to deep-dive, and hands the rest to the business model canvas.

## On invocation
Read `../../references/output-protocol.md`, `../../references/frameworks.md`, `../../references/customer-fit.md`, `../../references/scorecards.md`. Load `.value-to-market/context.md` (including the business-model-canvas seed written at init). Pull the assets (`v2m-tool-assets-assessment`), the market and competitor rings (`v2m-tool-market-benchmark`), the core values and the category. Draw the ecosystem actors from the BMC seed, the benchmark rings and the context; ask the user to confirm the actor list before mapping.

## Procedure
1. **List the actors on both axes.** Put every ecosystem actor (the brand, customers, suppliers, partners, channel and platform players, complementors, communities, regulators) on the rows and the same cast across the columns, so the matrix is actor-by-actor.
2. **Name the value in each meaningful cell.** For each live pair, name what the row actor delivers to the column actor: the **value to convey** and the **jobs it fulfils** for the receiver, including the backward flows a pipe diagram hides (advocacy, data, trust).
3. **Tag the delivery type** (keep the set fixed, after Cicero): **Creation** (brings new value into being), **Transformation** (changes received value's form), **Conveyance** (moves it along unchanged: distribution, access, reach; Cicero's original term was "Transfer", renamed here because Transfer names a maneuver in this method), **Exchange** (mediates a reciprocal swap), **Consumption** (uses it up, the endpoint).
4. **Trace the pipelines.** Read paths actor to actor to actor as value chains, where outcomes are inherited down the chain; note where a legacy carries forward.
5. **Mark intent, do not complete.** Populate only the cells that carry weight: the backward arrow you get for free and must protect, the thin intersection that needs building, the column about to turn scarce and priced, the row every other actor depends on. A full grid answers no question.
6. **Flag the deep-dive.** The customer-and-brand intersection earns a full `v2m-tool-value-proposition-canvas` later; flag any other intersection important enough to deserve its own canvas (a critical supplier, a make-or-break partner).
7. **Route intersections to the business model canvas.** Each live non-customer intersection typically becomes a BMC entry: a key partnership, a key activity or resource, a channel, a customer-relationship mode, or a revenue or cost line. Tag each with the block it feeds, so the matrix becomes raw material for `v2m-tool-business-model-canvas`; and hand the live exchanges to `v2m-tool-moat-defense` as candidate bridges and leverages.

## Recommendation
The intentional value map: the circled cells that point the next euro (the free backward arrow to protect, the thin intersection to build, the row all depend on), the value and jobs to convey at each with its delivery type, the intersections needing a full canvas, and the mapping of each to its BMC block. Feeds `v2m-tool-moat-defense`, `v2m-tool-value-proposition-canvas`, and `v2m-tool-business-model-canvas`.

Follow `output-protocol.md` for the reasoning file, self-score, and next step. Always produce the branded Word report, and since this tool is list-heavy always generate a branded Excel: a matrix tab (actors on both axes, each live cell holding the value, jobs and delivery-type tag) and an intersections tab (row actor, column actor, value to convey, jobs to fulfil, delivery type, circled-intent note, needs-own-canvas yes/no, BMC block it feeds).

# Value Proposition Verbalization

Turn the designed value into language a startup could say out loud and a brand team can build on. It embodies the Value Ladder and the core values; it never invents value the design did not establish.

## On invocation
Read `../../references/output-protocol.md`, `../../references/customer-fit.md` (the Verbalization section), `../../references/frameworks.md` (Promise Ladder, Core Values), `../../references/scorecards.md`. Pull the ladder read from `v2m-tool-value-ladder`, the core values, the canvas gain creators and pain relievers, and the premise recipient. If a rung is not earned by proof, do not verbalize at it.

## Procedure
1. **The Osterwalder-style sentence**: "Our [offering] helps [segment] who want to [job] by [gain creator] and [pain reliever], unlike [alternative]." One breath, specific, no rubber vocabulary.
2. **Payoff examples per rung**: write the VP as it would sound at each honestly-reachable rung (Solution, Value, Cultural Resonance, Higher Call).
3. **Semantic spaces**: the word territories to own and the antithesis in language to avoid; the metaphors and vocabulary that carry the values.
4. **Brand and comms seeds**: a tone-of-voice sketch (do and do-not pairs), a brand personality (a short archetype read), and draft mission, vision and purpose lines from the Higher Call rung and the core values. Mark all seeds as starting points.
5. **Refined copy and content review.** Go back over all the copy and content created across the run (taglines, promise lines, proof language, channel messages, launch content) and refine it into one coherent voice: fix off-voice lines, remove rubber vocabulary, align every piece to the semantic map. Present the before-and-after of the lines that mattered.
6. **Value propositions and elevator pitch per audience.** Refine the value proposition from the value ladder into a spoken form for each audience in turn: the **primary customer first**, then the stakeholders (investors, the board, internal teams) and the other ecosystem actors from the value matrix (suppliers, partners). For each, an elevator pitch tuned to what that audience values and the rung that lands with them, so the same value is pitched in the right register to each listener.

## Recommendation
One recommended value proposition sentence, the payoff set by rung, the semantic map, the brand/comms seeds, the refined copy-and-content pass, and the per-audience value propositions and elevator pitches (customer primary, then stakeholders and ecosystem actors). These feed `v2m-tool-guidelines` and `v2m-tool-keynote`. Score against the Verbalization scorecard.

Follow `output-protocol.md` for the reasoning file, self-score, and next step. No Excel for this tool. Produce a branded **Word** document (the sentence, the per-rung payoffs, the semantic map, the brand/comms seeds, the refined copy review, and the per-audience pitches) and a branded **presentation deck (PPTX and PDF)** that delivers the pitch emotionally: one idea per slide, the pitch to each audience and the rationale behind it, built to be felt, not only read.

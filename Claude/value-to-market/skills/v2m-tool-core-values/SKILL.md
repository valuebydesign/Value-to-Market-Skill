# Core Values

Always start from values, never the product. The best values are extracted from what you own, so you play almost for free.

## On invocation
Read `${CLAUDE_PLUGIN_ROOT}/references/output-protocol.md`, `${CLAUDE_PLUGIN_ROOT}/references/frameworks.md` (Core Values, Assets, Triple Constraint, Distance Scale, Evolution of Values), `${CLAUDE_PLUGIN_ROOT}/references/principles.md` (Transient Stability), `${CLAUDE_PLUGIN_ROOT}/references/scorecards.md`. Pull the graded inventory from `v2m-tool-assets-assessment`. Ask the audience, the industry, and any value the company must or must not stand for.

## Procedure
1. Asset test: every candidate value names the asset it draws on.
2. Card game: we are / we are not / we do not know. Plateau of five to six in a pool of ten to fifteen.
3. Classify: primary, secondary, tertiary, antithesis (name at least one antithesis).
4. Dimensions: place the set on the eight, one dominant and one supporting; resolve tensions with the Triple Constraint and Distance Scale.
5. Three-horizon evolution: launch, growth, scale; one substitution per cycle, by trigger; name the reserve pool.

## Recommendation
ONE recommended value set: primary (3 to 5), secondary, tertiary, antithesis, each with its backing asset and a confidence, plus the three-horizon evolution roadmap with triggers. The anchor for `v2m-tool-rhyming`, `v2m-tool-3p`, `v2m-tool-value-ladder`.

Follow `output-protocol.md` for the reasoning file, self-score, next step, and the branded deliverables (Word by default, Excel where list-heavy).

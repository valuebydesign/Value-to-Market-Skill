# Value Ladder

The ladder measures the height of the promise, not its truth. A high rung without the rungs beneath is inflated air with a panoramic view. The climb is a P&L decision, not a style exercise.

## On invocation
Read `${CLAUDE_PLUGIN_ROOT}/references/output-protocol.md`, `${CLAUDE_PLUGIN_ROOT}/references/frameworks.md` (Promise Ladder, Promise), `${CLAUDE_PLUGIN_ROOT}/references/scorecards.md`. Pull the promise and the proof from `v2m-tool-3p`.

## Procedure
1. Locate the current rung: Empty, Solution, Value, Cultural Resonance, Higher Call. Run the swap test for Empty.
2. Write the value proposition as it would sound at each rung the offer can honestly reach; mark which rungs are earned.
3. **Give the use cases for each rung's verbalization.** For every level, say when to use that phrasing and to whom (audience, channel, moment): the Solution rung for the pragmatic buyer comparing options, the Value rung for the outcome-driven, the Cultural Resonance rung for the identity-led audience, and so on. The same offer speaks at different rungs to different people; make the fit explicit rather than picking one voice for all.
4. **Say when to use the Higher Call, to whom, and when not to.** The Higher Call earns attention only for audiences and moments that welcome it (a mission-aligned segment, a brand moment, a category with a purpose stake) and backfires elsewhere: it reads as grandiose to a pragmatic buyer, as manipulative when the rungs beneath are unearned, and as noise in a transactional moment. Name the cases to reach for it and the cases to stay lower.
5. Choose the target rung; confirm the rungs beneath are earned; name the P&L consequence.
6. Confirm the target is proof-sized (with `v2m-tool-3p`).

## Recommendation
The current rung and the target rung with a climb plan, the per-level verbalization with its use cases (who, channel, moment), and the explicit guidance on when to raise the Higher Call and when not to. The climb and its cost are named. Feeds `v2m-tool-value-proposition-verbalization`. Score against the Promise and Ladder scorecard.

Follow `output-protocol.md` for the reasoning file, self-score, next step, and the branded deliverables (Word by default, Excel where list-heavy).

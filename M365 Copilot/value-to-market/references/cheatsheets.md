# Cheatsheets - one-page essentials

Compressed, printable essentials for each set and the core frameworks. `v2m-tool-cheatsheet` renders these (or a custom one) as a deliverable; every tool may cite the relevant strip. Keep any generated cheatsheet to one page: the tests, the failure modes, the one rule that matters.

## The whole method on a card

- **Formula:** VP = [ Channels x Core Values x Promise ] + USP. The bracket multiplies (any zero zeroes it); USP is additive.
- **Order of work:** assets, values, premise, promise, proof, category, channels. Never invert.
- **3P diagnostic (30 seconds):** no premise, irrelevant; no promise, weak; no proof, not trusted.
- **Four Principles:** Context (who set the rules), Reality (in which world are we necessary), Transient Stability (a stable value is no longer valuable), Corollary (leaps need a new frame).
- **Value to Market:** the shortest path to value; spend 6% upstream; envision, design, engineer.

## Set 1 - Assess

Read the field with the customer's yardstick. Ocean (red/blue/new), Category Value Map (five lenses, white space), the fifteen challenges audit, the eight-family asset sweep. Test: "we have no real competitors" is the most dangerous sentence in business.

## Set 2 - Strategy (company)

Values from assets (asset test), premise as a deliberate repellent, category before offer, moat as structural uniqueness, power figure read from market condition, rhyming so the portfolio compounds. Test: better is not different; only a new frame produces leaps.

## Set 3 - Design (per line of business)

Premise (who yes / who no / turnstile), promise on the right rung (five ingredients, breakable, proof-sized), proof across four families with one costly, MOA so the audience can receive it, price on the value stick, channels as triplets. Test: an unperceived benefit does not exist.

## Set - Customer & Fit

Understand the customer as jobs, map value to them, check the fit. Jobs at three levels (functional, social, emotional), generated across audiences and cases and stress-tested with modifiers (under stress, tight time, limited resources, limited knowledge), tagged by objective (personal gain, task, business advantage, greater call). Then the Value Proposition Canvas and the fit, ending in a ranked feature set. Test: fit is real only for pains and gains the customer ranks high.

## Set 4 - Market

Move through the market as wilderness. Three priorities: get to value, shake pursuers, gain advantage. Win without fighting; a fight is the most expensive way to gain ground. Plan the strike as a lightning strike, not a drip.

## Set 5 - Engineer

Translate strategy into specs: channel briefs, proof specifications, a measurement/KPI plan (few indicators, renewed against decay), a validation plan (what would falsify this, tested early), automation, and the internal onboarding kit. Cures the value-to-execution gap.

## Set 6 - Deliver

Turn the reasoning files into artifacts: the full report (editorial Word/PDF), the keynote deck, guidelines, cheatsheets, and the section scorecards. Client-shareable, authored, restrained.

## The tests, collected

- Swap test (Empty Promise): swap your payoff with a rival's; does anyone notice?
- Read-aloud test (Premise): does the wrong customer self-select out?
- Ten-times-capital test (Moat): what would a rival with ten times your capital still fail to replicate?
- Asset test (Values): which asset does this value draw on?
- Off-the-cuff baseline (Assess): write the VP from memory, then measure the distance at challenge 11.
- Winners extend, losers orphan (Rhyming): does the next move reuse something we already own?

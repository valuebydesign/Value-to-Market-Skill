# Hoang's Four Principles

The philosophical engine beneath the frameworks. A principle is a rule reused across similar situations, written so it can be tested and handed on (format borrowed from Ray Dalio). Use the operational question of each as a probe during any command.

## 1. Principle of Context

> The set of rules defines the playing field; the opposite is not a certainty. Therefore reality is never the context.

The context is always a selection of reality, made by someone. If you did not make it, you are playing on a field drawn by someone else. Every strategic analysis begins by recognizing that the rules you are judged by were chosen, and could be chosen differently.

**Operational question:** Who defined the rules we are judged by?

## 2. Principle of Reality

> There are infinite realities among all possible universes, but only in one do we make meaningful sense.

Category design is not inventing any world whatsoever: it is finding and building the only context in which your assets, values and promises compose a full meaning. The work is to locate the one world where you are not optional.

**Operational question:** In which world are we necessary?

## 3. Principle of Transient Stability

> The only way to make a value stable in time is tangibilization; however, a stable value is no longer valuable.

Values wear out with use. When a value tangibilizes into a standard, it stops differentiating and becomes a hygienic requirement. The portfolio demands perpetual maintenance and a reserve pool: every value you successfully stabilize is a value you are spending.

**Operational question:** Which of our values is tangibilizing into a standard, and what does the reserve pool field to replace it?

## 4. Corollary to All Principles

> Every major change within the value architecture can only be implemented through a change of the frame of reference.

Better is not different. Within a given frame, improvement produces increments; only a new frame produces leaps. This explains why category kings capture 76% of the value: they did not improve inside the field, they changed the field.

**Operational question:** Are we trying to win by being better inside the current frame, or by changing the frame itself?

# Tools, Procedures, and the AI Layer

The operational form of the frameworks. Where frameworks explain, tools execute. Each tool is tagged by Run phase and grouped diagnostic / generative / evaluative. Use the exact procedure when a command invokes a tool.

## Diagnostic (read the situation)

- **Stage Assessment** - seven true-false statements of the run, read in order; the first false marks the project's real phase and the next thing to open. Run any time. Cuts the assumption that you are further along than you are.
- **Ocean Diagnosis** - locate a line of business in red / blue / new waters via the six-question diagnostic. Count answers, trust the majority.
- **Category Value Map** - score every player across five value lenses (functional, emotional, social, ethical, transformational); read crowded zones and white spaces. Only empty cells your assets can prove are candidate frames.
- **Competitor Figure-and-Ladder Read** - tag each rival's Power Shifting figure and Promise Ladder rung.
- **MOA Audit Grid** - four questions per dimension (Motivation, Opportunity, Ability) per reference subject, scored red/yellow/green; attack the reddest column first; B2B fills it twice (decision-maker and user).
- **USP vs VP Clarification Canvas** - end the conflation: the USP is the additive object; the VP is the whole bracket.
- **Paradox Finder** - surface the declared-versus-practiced gap deliberately.

## Generative (build the proposition)

- **Eight-Family Asset Sweep** - inventory across the eight families; per entry ask: monetizable? are we monetizing it? how defensible (unique/replicable/imitable)? The unique-plus-dormant entries are the crimes list, top of the agenda.
- **The Table Protocol** - the values session: half a day, five to eight mixed people (not just leadership), silent individual sorting, compare maps, the asset test, priorities and antitheses. Produces the signed values page.
- **Premise Statement Builder** - write the statement; apply three rules (not aspirational, clear, in balance) with toxic profiles in view; run the read-aloud test (does the wrong customer self-select out?) and the turnstile check (can the selection be built into the economics?); produce variants.
- **Promise Verbalization Template** - compose the five ingredients (clause, object, recipient, enforcer, conditions); pass three gates (verifiable breakability, type check, sizing to the proof inventory); map each ingredient back to the verbalized promise.
- **Proof Design Canvas** - per promise, three columns: what is promised, proof in the first thirty days, recurring proof each cycle. All four proof families must appear and at least one must cost. Where a column stays empty, resize the promise rather than leave the gap.
- **Name the Category** - list main, sibling and adjacent categories with attributes; cherry-pick the best of each; compose and name your own. Half a day, highest-yield investment in strategy.
- **Channel Census and Triplet Map** - map value × recipient × channel as single units; build the repair list.
- **Multi-Proposition Matrix** - portfolio coherence with local resonance; watch spillover.
- **The 97% Pipeline** - the demand-pyramid education engine (only 3% buy now).
- **Rhyming Framework** - score a company's launches as music on a five-line staff, name the movement, beats and tempo, then plan the next Singleton so it rhymes with the pattern and the market. Full method: classification rubric, Rhyme-Check Scorecard, Next-Note Selector, tempo metrics, antipattern pre-mortem. See `rhyming.md`; run with `/vp-rhyming`. Feeds from the Eight-Family Asset Sweep and the Inflection-Point Audit.

## Evaluative (test and price)

- **Defensibility Ladder** - class every asset unique / replicable / imitable.
- **Distance Scale** - make a trade-off visible and decided (lever, fulcrum).
- **Promise Ladder Mapping** - the rung, the gap, the climb plan.
- **Value Stick Quantification** - measure the four notches (WTP from tests and interviews, price, costs, WTS); read the three slices (delight, margin, supplier surplus); decide how to spend the delight slice; build the sacrifice-removal list by cost-benefit.
- **Inflection-Point Audit** - what each euro of premium really pays for.
- **Power Posture Audit** - scan for confused power (contradictory figures).
- **Spillover Assessment** - multichannel without incoherence.

## The AI operating layer (Chains and Combinations)

The executable layer of the method: prompt chains V0-V22 and combinations C0-C16 (the Prompt Collection). V0 is the seed value proposition draft; later chains refine premise, promise, proof, positioning, and produce the report. When a command mentions "run V0" or a chain, it means: produce the corresponding artifact in the method's voice and vocabulary, sized to the evidence at hand. If the user has the Value Proposition Vault or the platform open, prefer their live artifacts as source of truth; otherwise build from the input and this reference.

## Optional grounding sources

If the user has connected their own reference materials (a notes vault, a manuscript, a prior strategy document, a brand or research library), treat them as read-only source of truth: cite the specific note or section, and never contradict them. Do not write into them. If none are connected, build from the user's input and these bundled references.

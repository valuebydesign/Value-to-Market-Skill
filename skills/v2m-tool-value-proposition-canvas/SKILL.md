# Value Proposition Canvas

Test fit before building. Fit is real only for pains and gains the customer ranks high.

## On invocation
Read `references/output-protocol.md`, `references/customer-fit.md`, `references/frameworks.md` (The Value Proposition Canvas), `references/scorecards.md`. Pull the job set from `v2m-tool-jobs-to-be-done`. Ask for the current offering and its features.

## Procedure
1. **Customer profile**: jobs (from JTBD), pains, gains, each ranked by how much the customer cares.
2. **Value map**: products and services, pain relievers, gain creators.
3. **Fit**: match every ranked pain to a reliever and every ranked gain to a creator. Do not claim fit for anything nobody ranks high.
4. **Feature recommendation**: keep the features that relieve a ranked pain or create a ranked gain; cut-list the rest.

## Recommendation
The filled canvas as a deliverable, the fit read (where it holds and where it does not), and a ranked, fit-justified feature set with a cut list. Route to `v2m-set-4-design` for the 3P.

Follow `output-protocol.md` for the reasoning file, self-score, next step, and the branded deliverables (Word by default, Excel where list-heavy).
